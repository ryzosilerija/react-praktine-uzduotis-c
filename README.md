# React praktinė užduotis

Trys atskiri Vite + React projektai:

- `task-list` – užduočių sąrašas
- `shopping-cart` – krepšelio sistema
- `guess-game` – skaičių spėjimo žaidimas

## Paleidimas

```bash
cd task-list
npm install
npm run dev
```

Kitiems projektams – tas pats, tik atitinkamame aplanke.
